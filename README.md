# Corner-to-Corner Studio

A chart studio for corner-to-corner crochet, by [Chet Chic](https://chetchic.com).

Open the app: [c2cstudio.chetchic.com](https://c2cstudio.chetchic.com)

Design a graph, follow the diagonal while you crochet, and download a finished pattern. Each square is one block. Yarn letters run backward from Z, and Z is always the background.

## What you can do

- Draw with paint, fill, pick, erase, and move. Add block letters.
- Turn a photo into a chart, or start from a template.
- Switch between Design and Project. In Project mode, pin a row, see the direction of work, and mark rows done.
- Set columns and rows, starting corner, stitch style, and block gauge.
- Estimate finished size and yardage from your yarn and hook.
- Save snapshots, export the chart, and download the written pattern or a full PDF.

## Manual

The full how-to is at [c2cstudio.chetchic.com/manual.html](https://c2cstudio.chetchic.com/manual.html).
