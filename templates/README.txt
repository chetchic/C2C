C2C Studio - your own default templates
=======================================
Designs listed in index.json appear in the Charts menu under "Chet Chic designs".

1. In C2C Studio, make the chart. Options tab > Export project. You get a .json file.
2. Put that file in this templates folder (for example rose.json).
3. Edit index.json. It is a list. Example with two designs:

   [
     { "file": "rose.json", "label": "Rose" },
     { "file": "example-heart.json", "label": "Heart (example)" }
   ]

4. Upload the changed files to GitHub (main branch). Reload the studio after a minute or two.

index.json ships empty ([]), so nothing extra shows until you add an entry.
example-heart.json is a ready example you can list to try it, or delete.
Free members see 10 templates a week, picked from the built-in ones plus these.
